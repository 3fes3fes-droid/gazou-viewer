# 画像

Chromebookを主対象にした、画像を開いて同じフォルダを前後に見るだけの最小Androidビューアです。

## 動作

- ChromeOSの「ファイル」から JPG / JPEG / PNG / WEBP をこのアプリで開く
- 開いた画像を即表示
- 同じフォルダ内の対応画像をファイル名の自然順で読み込む
- `←` 前
- `→` 次
- 先頭/末尾を越えない（何も起きない）
- `Space` で 1枚表示 / 2枚表示を切替
- 2枚表示では `←` / `→` が2枚単位で移動
- 2枚表示の末尾が1枚だけなら1枚を画面いっぱいに表示
- `Esc` で終了
- 黒背景、UI・ファイル名・枚数・ボタンなし
- 縦横比を維持し、切り抜かず画面内に最大表示
- ChromeOSでは起動時に最大化を要求し、AndroidのシステムUIを没入モードで隠す

## 初回だけ必要なこと

同じフォルダ内の次/前の画像をMediaStoreから読むため、初回にAndroid標準の「写真と動画」アクセス許可が1回だけ出ます。フォルダ選択画面は出しません。

許可しない場合も、ChromeOSから渡された最初の1枚は表示できますが、同じフォルダの前後列挙はできません。

## 対応範囲

- Android 9 (API 28) 以上
- targetSdk 33（Android 14+の「選択した写真だけ」部分アクセスをこのローカルビューア用途で発生させないため）
- JPG / JPEG / PNG / WEBP

## ビルド

Android Studioでこのフォルダを開き、`app` の debug または release APK をビルドします。
